**共有リンク「閲覧ログ」画面仕様（社内側）**

目的: 「見た/見てない」の水掛けを防ぐ。「見た記録」以外の表現は禁止。

**画面名**
- 共有リンク詳細

**表示項目（上段）**
- 現場名 / 相手名
- 共有リンク状態: 有効 / 期限切れ / 失効
- 期限: 残り日数
- PIN: あり / なし

**操作**
- [リンクをコピー]
- [失効する]（`share_link.revoke`）
- [再発行]（再生成、旧リンクは即失効）

**閲覧ログ一覧**
- 列: 日時 / 回数 / 端末 / 参照内容
- 端末: `スマホ` `PC` `不明`
- 参照内容: `ページ` / `PDF` / `写真`

**文言**
- 見出し: 見た記録
- 空状態: まだ見た記録はありません
- 補足: 「見た記録は閲覧の事実のみを示します」

**状態**
- ログ取得中: 「読み込み中」
- ログなし: 「まだ見た記録はありません」
- 失効: 「このリンクは失効しました」

**並び順**
- 新しい順（最新が上）

**権限**
- `share_link.view` 以上で閲覧可
- `share_link.revoke` で失効操作可
