**役割別UIメニュー（スクリーン別）**

前提: 3画面原則（今日 / 連絡 / 日報・写真）。管理系は別メニュー。

**Owner**
- 今日
- 連絡
- 日報・写真
- 現場管理
- 取引先管理
- 出力
- 監査ログ
- メンバー管理
- 契約/請求

**Admin**
- 今日
- 連絡
- 日報・写真
- 現場管理
- 取引先管理
- 出力
- 監査ログ
- メンバー管理

**現場（現場監督/職長/作業員）**
- 今日
- 連絡
- 日報・写真

**事務（事務員/経理）**
- 今日
- 連絡
- 現場管理
- 取引先管理
- 出力

**Partner（外部協力会社）**
- 連絡（割当スレッドのみ）

メニューの出し分けルール:
- 権限がない項目は非表示。
- 画面内のボタンも権限で自動非表示。
- 直接URLアクセスは403 + 「使えません」。
