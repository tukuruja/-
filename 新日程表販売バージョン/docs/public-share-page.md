**共有リンク（公開ページ）UI仕様**

目的: SMS/LINEで入る必要なしでも「見たか/見てないか」を言い訳できない証跡を残す。

**表示/非表示ルール**
- 表示: 現場名、相手名、更新日時、添付一覧（PDF/写真/資料）。
- 非表示: 社内メモ、社内限定コメント、内部タグ。
- 閲覧専用: 編集や返信は不可。

**PIN有無による挙動**
- PINなし: すぐ表示。
- PINあり: PIN入力画面 → 正しければ閲覧開始。
- PIN失敗: 5回で10分ロック。

**状態表示**
- 有効: 「有効（残りX日）」
- 期限切れ: 「期限が切れました」
- 失効: 「このリンクは使えません」
- PIN違い: 「PINが違います。もう一度入れてください」

**証跡（見た記録）**
- 表示名: 「見た記録」
- 記録項目: 日時 / 回数 / 端末種別（PC/スマホ）
- 表示先: 共有リンクの詳細画面（社内側）

**UI構成（固定）**
1. ヘッダー: 現場名 / 相手名
2. サマリ: 更新日時 / 共有リンクの状態
3. 一覧: 添付カード（PDF/写真/資料）
4. フッター: 「このページは閲覧のみです」

**操作**
- 添付カードをタップ → その場でプレビュー
- ダウンロードは明示ボタン（誤タップ防止）

**文言（抜粋）**
- 見出し: 「共有ページ」
- 補足: 「SMS/LINEで入る必要なしで見られます」
- ボタン: 「見る」
- ボタン: 「ダウンロード」
