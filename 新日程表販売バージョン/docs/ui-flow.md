**UI Flow (Contact Note)**
```mermaid
flowchart TD
  A[アプリ起動] --> L[SMS/LINEで入る]
  L -->|SMS| L1[SMSコード入力]
  L -->|LINE| L2[LINE認証]
  L1 --> M[会社選択]
  L2 --> M
  M --> B[今日]

  B -->|現場を開く| C[連絡ノート（時系列）]
  B -->|日報/写真| D[日報・写真]

  C --> E[入れる]
  E --> E1[写真]
  E --> E2[メモ]
  E --> E3[書類]
  E1 --> C
  E2 --> C
  E3 --> C

  C --> F[送る]
  F --> G[共有シート]
  G --> H[LINE/Gmail/メール/SMS]
  H --> I[相手]

  J[外部アプリ] -->|共有 → アプリ| K[現場を選ぶ]
  K --> L3[相手を選ぶ]
  L3 --> C

  C --> N[共有リンク]
  N --> O[閲覧ページ（SMS/LINEで入る必要なし）]
  O --> O1[PIN入力]

  C --> P[電波待ち]
  P --> C
```

```text
  [SMSで入る]   [LINEで入る]

  ・電波が弱い → あとでOK
-------------------------------------------------

  [_ _ _ _ _ _]

  [入れる]

[閲覧ページ（SMS/LINEで入る必要なし）]
-------------------------------------------------

  共有リンク: 有効（7日）

  ・工程表（最新版）
  ・見積PDF
  ・写真 3枚

  このページは閲覧のみです

  PINが必要な場合
  [PINを入れる]  [_ _ _ _]
  [見る]

  状態:
  - 期限切れ → 「期限が切れました」

```

**文言ルール**
- ボタンは短い動詞のみ: `入れる` `撮る` `送る` `見る`
- 状態表示は責めない: `電波待ち（あとで送る）`
- 「見た記録」以外は使わない: `見た記録` のみ表示
