**PIN/共有リンク UI文言辞書**

**作成側（アプリ内）**
| 種別 | 文言 |
|---|---|
| ボタン | 共有リンク |
| ボタン | コピー |
| ボタン | 送る |
| ボタン | 失効する |
| ボタン | 再発行 |
| スイッチ | PINをかける |
| ヒント | 4〜8桁の数字 |
| 状態 | 有効（7日） |
| 状態 | 期限切れ |
| 状態 | 失効済み |
| 状態 | 見た記録 |
| エラー | 期限が切れました |
| エラー | このリンクは使えません |
| エラー | 電波が弱いです。あとで送ります |

**閲覧側（SMS/LINEで入る必要なしページ）**
| 種別 | 文言 |
|---|---|
| 見出し | 共有ページ |
| サブ | SMS/LINEで入る必要なしで見られます |
| ボタン | 見る |
| フィールド | PINを入れる |
| ヒント | 4〜8桁の数字 |
| 状態 | PINが必要です |
| 状態 | PINを確認中 |
| エラー | PINが違います。もう一度入れてください |
| エラー | 期限が切れました |
| エラー | このリンクは使えません |

**権限・安全系の文言**
| 種別 | 文言 |
|---|---|
| 通知 | 失効しました |
| 通知 | PINを外しました |
| 通知 | PINをかけました |
| 通知 | 見た記録を保存しました |

**表示ルール**
- 「見た記録」以外は使わない。必ず「見た記録」。
- エラーは責めない。否定は短く、次の行動を出す。
- 送信中/電波待ちは必ず表示。
