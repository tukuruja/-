段階的移行（トロイの木馬戦略）

  • Phase 1: デジタルFAX（1〜3ヶ月）閲覧のみ。
  • Phase 2: スタンプ参加（4〜6ヶ月）押すだけ報告。
  • Phase 3: カメラ/音声で完全移行（7ヶ月以降）。

実装ロードマップ（機能追加）

  • Phase 0: 連絡ノート＋共有リンク＋証跡。
  • Phase 1: 予定→資源追加→日報導線。
  • Phase 2: 外注区分＋累計表示。
  • Phase 3: 画質改善＋非同期強化。
  • Phase 4: 監視/アラート閾値の会社別カスタム。

リスク登録簿（TOP10）

  • 共有リンク誤送信 → PIN/期限/失効/ログ/再発行。
  • 同期不整合 → Idempotency + 競合解決。
  • 写真肥大化 → 2段階圧縮。
  • 低スペ端末遅延 → OS下限設定。
  • 証跡の過信 → 「見た記録」以外の表現禁止を固定。
  • CSV互換破壊 → 列追加のみ。
  • 権限誤設定 → テンプレ＋監査ログ。
  • 共有漏洩 → ログ＋即失効。
  • 操作迷い → 次にやること固定表示。
  • 画面増殖 → 3画面原則。
